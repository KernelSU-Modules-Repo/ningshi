# Ningshi

Ningshi kills apps the instant they launch — before any app code runs — based on rules you set: always-on block, lock-screen block, time windows, and duration limits with cooldown. Per-app or shared-pool groups. Configure everything in the WebUI.

**For full documentation, build instructions, screenshots, and source code, see the main repository:**
👉 **https://github.com/yuciss/ningshi**

---

## 凝时

凝时在被限制的 App 启动的瞬间将其杀死——早于任何一行 App 代码执行——依据你设定的规则：常驻拦截、锁屏拦截、时间段拦截、时长限制 + 冷却期。支持单个应用或共享额度的分组，所有设置都在 WebUI 里完成。
